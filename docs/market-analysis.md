# 全国购房决策 App 市场分析

更新时间：2026-08-23

## 结论

机会不在于再造一个房源平台。贝壳、链家、安居客已经覆盖海量房源、筛选、
地图、VR 与经纪服务。更值得切入的是一个由买方掌控的私人决策工作台：

`预算 -> 板块研究 -> 看房证据 -> 横向比较 -> 尽调 -> 交易`

产品应沉淀用户自己的观察和决策过程；需要权威数据时，再跳转或接入房源平台、
政府、银行及专业服务。

## 用户问题

不同城市的购房者通常只知道总预算，却难以进一步回答：

- 购房资格允许买什么，家庭现金流能舒适承担什么；
- 应该从哪些行政区和板块开始；
- 每次看房应该检查哪些事项；
- 连续看过多套后，如何避免印象混乱和情绪决策；
- 从核验、谈判、贷款、税费到过户，下一步应该做什么。

现有平台主要优化房源发现与交易转化，对个人看房证据、跨楼盘复盘、预算压力和
决策过程的支持较弱。

## 竞品分析

| 产品 | 优势能力 | 沪居的差异化空间 |
| --- | --- | --- |
| 贝壳 / 链家 | 结构化房源、地图找房、VR、价格历史、经纪网络 | 用户自己的现场笔记与判断不是主流程 |
| 安居客 / 58 | 房源覆盖广、热力图、直播看房、顾问服务 | 信息质量需要甄别，比较和核验仍依赖用户 |
| 房天下 | 楼盘测评、市场内容、房产类型丰富 | 从研究到个人决策的链路较分散 |
| 幸福里 | 内容化发现、短视频、年轻用户触达 | 严谨的看房后评估不是核心 |
| 地图 App | POI、通勤路径、学校医院商业配套 | 没有持续的购房工作流与楼盘决策日志 |

## 产品定位

**名称：** 沪居 HuJu

**价值主张：** 无论在哪座城市，让每一次看房都成为下一次判断的证据。

核心循环：

1. 设置预算、现金、通勤锚点和不可妥协项。
2. 选择当前城市，从行政区和板块建立探索范围。
3. 两分钟内记录照片、评分、语音、加分项与风险。
4. AI 汇总证据，指出偏好、冲突和缺失检查项。
5. 比较最终候选，并推进购房尽调清单。

## MVP 信息架构

| 模块 | 目标 |
| --- | --- |
| 今日 | 展示进度、下一步、预算脉搏和最近看房 |
| 地图 | 呈现已看位置、候选状态、板块与通勤 |
| 看房日志 | 时间线、筛选、现场笔记、评分与复看状态 |
| AI 决策助手 | 基于证据排序，提示风险和追问 |
| 购房规划 | 预算测算与购房流程清单 |

## AI 原则

- 明确区分客观事实、用户感受、模型推断和未经核验的信息。
- 每条推荐必须展示理由和对应的用户记录。
- 不把生成价格包装成官方估值。
- 政策、学区、产权、税费与贷款结论必须提示用户实时复核。
- 证据不足时优先追问，而不是补造结论。

## 全国化市场判断

中国各城市的限购、公积金额度、首付比例、税费与学区规则存在明显差异，政策层必须
同时携带城市、时间戳和权威来源。相关变量应由可更新的 `policy snapshot` 管理，
不应把某一城市规则复用到全国，也不应固化为法律建议。

国家统计局 70 个大中城市住宅销售价格指数适合观察城市级变化，但不能代表具体板块、
小区或房源。产品应先按城市隔离候选和购房流程，再基于用户预算、通勤和本地同类房源
比较，并明确数据更新时间。上海研究继续作为首个城市案例，不再限制产品服务范围。
